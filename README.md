# Andrii Dudar — Developer Portfolio

A responsive, single-page portfolio website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive layout for desktop, tablet and mobile
- Dark visual theme with custom CSS illustrations
- About, skills, projects, services and contact sections
- Project filters (Backend, Python, Web, C++)
- Mobile navigation
- Reduced-motion support
- No build tools or framework required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `andrii-dudar-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` and `favicon.svg` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Before publishing
- Confirm that the displayed email and external links are correct.
- Replace any project descriptions or links if the underlying repositories change.
- Projects marked **PLANNED** are portfolio roadmap concepts, not completed applications. Update their status only after implementation.
- Add real screenshots or live demo links when those become available.
